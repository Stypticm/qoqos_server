# 📱 QOQOS — AI-оркестрируемая система жизненного цикла устройств

> **QOQOS** — операционная система управления замкнутым циклом устройств.  
> **Бизнес, управляемый искусственным интеллектом.**

Телефон не продаётся один раз. Он живёт циклом:  
**Buyback → Diagnostics → Repair → Rent → Resell → Recycle**

Цель — довести автоматизацию операционных решений до 90% через **multi-agent AI architecture**. 

## 🔁 Жизненный цикл устройства
- **Buyback** – онлайн-оценка и скупка Б/У телефонов
- **Diagnostics** – автоматизированная диагностика (AI + сенсоры)
- **Repair** – управление ремонтными работами и запчастями
- **Rent** – краткосрочная аренда устройств
- **Resell** – перепродажа восстановленной техники
- **Recycle** – экологичная утилизация

## 🚀 Что мы создаём

Систему, в которой ИИ оценивает технику, принимает финансовые решения, управляет логистикой и оптимизирует доходность каждого устройства. Человек остаётся стратегом.

## 🧭 Наша позиция

> Без грантов. Без венчурных денег. Без иллюзий.

Есть идея: **ИИ может управлять реальным бизнесом эффективнее человека.** Мы это проверяем здесь и сейчас.

## ⚙️ Технологии

- **Multi-agent AI orchestration**
- **Nuxt.js** фронтенд (buyback-landing)
- **Python/FastAPI** — мозг «Валера» 
- **Go** — api-service
- **Qdrant** — векторная память
- **Ollama** — локальные LLM + эмбеддинги
- **PostgreSQL** — пользователи, чат-ответы
- **Telegram Bot** — эскалация к оператору

## 🧠 Архитектура «Валеры»

Запрос от пользователя приходит в `valera_brain.py` (FastAPI, port 8001).  
Мозг получает эмбеддинг вопроса через Ollama (`nomic-embed-text`), ищет релевантные фрагменты в Qdrant (`qoqos-knowledge`), подмешивает их в системный промпт и отправляет LLM (`qwen2:1.5b`). 

Если ответ содержит тег `<ESCALATE_REASON>` или ключевые слова про оператора — `chat.post.ts` отправляет уведомление в Telegram и показывает пользователю заглушку.  
Оператор отвечает в Telegram → `telegram_bot.js` сохраняет ответ в PostgreSQL (`ChatReply`) → фронтенд poll'ит и показывает клиенту.

## 📂 Структура базы знаний

Файлы `.txt` в `QOQOS_KNOWLEDGE/` → `ingest_knowledge.py` разбивает на чанки → Ollama эмбеддит → Qdrant.  
При обновлении файлов перезапустите `py ingest_knowledge.py`.

## 🗄️ Схема БД (PostgreSQL)

- **User** — аккаунты сотрудников/клиентов  
- **ChatReply** — ответы операторов, привязанные к `guestId`

## 🛠 Как запустить

1. Поднять инфра:
```powershell
cd qoqos_server
docker-compose up -d
```

2. Загрузить знания в Qdrant (один раз или при обновлении файлов):
```powershell
py ingest_knowledge.py
```

3. Запустить бота и мозг:
```powershell
npm run dev
```
