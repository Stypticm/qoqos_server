- UI компоненты максимально чистые (отвечают только за отображение).
- Выноси бизнес-логику и state в hooks (React) / composables (Vue) / services.
- Обязательно обрабатывай loading, error, empty states.
- Учитывай edge cases (defensive code).
- Избегай магии, неявного поведения, мёртвого кода.
- Никакого hardcode (используй константы).
- Централизованные конфигурации (breakpoints, adaptive design).
- Оптимизируй re-renders только при реальной необходимости.
- Стремись к минимализму и простоте решений.
